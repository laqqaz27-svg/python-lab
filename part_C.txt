PART C - WRITING AND COMMITTING PYTHON CODE

1. utils.py

def square(n):
    return n ** 2

def is_even(n):
    return n % 2 == 0

def celsius_to_fahrenheit(c):
    return (c * 9 / 5) + 32


2. main.py

from utils import square, is_even, celsius_to_fahrenheit

number = float(input("Enter a number: "))

print("Square:", square(number))

if is_even(number):
    print("Even")
else:
    print("Odd")

print("Fahrenheit:", celsius_to_fahrenheit(number))


3. How Python import connects main.py to utils.py

The main.py file uses the statement "from utils import square, is_even, celsius_to_fahrenheit" to import the three functions from utils.py.
 Since both files are in the same src folder, Python can find the utils module. This allows main.py to use the functions defined in utils.py without rewriting their code.
